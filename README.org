* Building instructions

** Requirements

- GCC
- GNU Make
- Doxygen (for generating documentation)

*** Vendored dependencies

- Unity (v2.6.1)
- cJSON (v1.7.19)
- PDFio (v1.6.1)

** Build

Clone the repository

#+BEGIN_SRC bash
  git clone --recurse-submodules git@github.com:UCL/amr-genome-reporting
#+END_SRC

Compile the code

#+BEGIN_SRC bash
  make
#+END_SRC

Build and run Unity tests

#+BEGIN_SRC bash
  make test
  make -C tests run
#+END_SRC

Build documentation

#+BEGIN_SRC bash
  make docs
#+END_SRC
