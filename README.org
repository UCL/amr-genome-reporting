#+TITLE: AMR Genome Reporting CLI
#+AUTHOR: David Guzman

Single-level bacterial genome reporting developed for clinical settings.

* Building instructions

** Requirements

- C compiler: GCC (minimum version 9+) or Apple clang (minimum version 9+ on MacOS 10+)
- GNU Make
- ZLIB 1.1 or higher
- Doxygen (for generating documentation)

*** Vendored dependencies

- Unity (v2.6.1)
- cJSON (v1.7.19)
- PDFio (v1.6.1)

** Build

Clone the repository

#+BEGIN_SRC bash
  git clone --recurse-submodules git@github.com:UCL/amr-genome-reporting
#+END_SRC

Compile the code

#+BEGIN_SRC bash
  make
#+END_SRC

Build and run Unity tests

#+BEGIN_SRC bash
  make test
  make -C tests run
#+END_SRC

Build documentation. Doxygen is required to run this target.

#+BEGIN_SRC bash
  make docs
#+END_SRC

Build in debug mode

#+BEGIN_SRC bash
  make debug
#+END_SRC

* Run

After compilation run the application against the provided test file.

#+BEGIN_SRC bash
  ./build/bin/amr_gen_reporting tests/complete.json
#+END_SRC
