#+TITLE: AMR Genome Reporting CLI
#+AUTHOR: David Guzman

Single-level bacterial genome reporting developed for clinical settings.

* Building instructions

** Requirements

- C compiler: GCC (minimum version 9+) or Apple clang (minimum version 9+ on MacOS 10+)
- GNU Make
- Doxygen (for generating documentation)
- Buildah, Podman, or Docker (for building containers)
- Conda-Build (for conda packages)

*** Vendored dependencies

- Unity (v2.6.1)
- cJSON (v1.7.19)

** Build

Clone the repository

#+BEGIN_SRC bash
  git clone --recurse-submodules git@github.com:UCL/amr-genome-reporting
#+END_SRC

Compile the code

#+BEGIN_SRC bash
  make
#+END_SRC

Build and run Unity tests

#+BEGIN_SRC bash
  make test
  make -C tests run
#+END_SRC

Build documentation. Doxygen is required to run this target.

#+BEGIN_SRC bash
  make docs
#+END_SRC

Build in debug mode

#+BEGIN_SRC bash
  make debug
#+END_SRC

*** Packages

Build packages

#+BEGIN_SRC bash
  make container # assumes docker, lima, etc. daemon is running

  make conda # assumes conda init has already been executed
#+END_SRC

To build the package manually:

**** OCI Container

Build with docker cli

#+BEGIN_SRC bash
  docker build -f pkg/container/Containerfile -t amr-gen-reporting:1.0 .
  # test with
  docker run --rm -v ".:/input" amr-gen-reporting:1.0 /input/tests/complete.json
#+END_SRC

**** Conda

#+BEGIN_SRC bash
  conda activate base
  conda-build pkg/conda/recipe
#+END_SRC


* Run

After compilation run the application against the provided test file.

#+BEGIN_SRC bash
  ./build/bin/amr_gen_reporting tests/complete.json
#+END_SRC
